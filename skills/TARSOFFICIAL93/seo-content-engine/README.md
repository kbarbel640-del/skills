# SEO Content Engine

> Generate SEO-optimized blog posts with keyword research and competitor analysis

## 🚀 Quick Start

```bash
# Copy to your OpenClaw skills folder
cp -r seo-content-engine ~/.openclaw/skills/

# Or install via ClawHub (when published)
npx clawhub@latest install seo-content-engine
```

## ✨ Features

- 🔍 **Keyword Research** — Validates search potential
- 📊 **Competitor Analysis** — Analyzes top-ranking content
- ✍️ **Content Generation** — Creates structured articles
- 🎯 **SEO Optimization** — Built-in best practices
- 💰 **Freemium Model** — Free tier + premium upgrade
