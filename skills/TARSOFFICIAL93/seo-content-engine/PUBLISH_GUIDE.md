## 📋 Come Pubblicare su ClawHub

### Metodo 1: ClawHub CLI (Consigliato)

```bash
# 1. Installa ClawHub CLI
npm install -g clawhub

# 2. Login (apre browser)
clawhub login

# 3. Naviga nella cartella skill
cd ~/.openclaw/workspace/skills/seo-content-engine

# 4. Pubblica
clawhub publish . \
  --slug seo-content-engine \
  --name "SEO Content Engine" \
  --version 1.0.0 \
  --tags "seo,content,marketing,writing,automation"
```

### Metodo 2: GitHub PR

```bash
# 1. Forka https://github.com/openclaw/skills

# 2. Clona il tuo fork
git clone https://github.com/TUO_USERNAME/skills.git
```
